# Red West V1 Scope

## Product Goal
Deliver a polished, replayable arcade survival shooter that feels complete enough for a paid early release.

## Target Platform
- Desktop browser (current build)
- Follow-up packaging target: desktop app distribution

## Core Loop (V1)
- Start run
- Survive structured enemy waves
- Collect loot and switch weapons based on situation
- Reach higher waves and improve leaderboard score
- Save run result and retry

## Must-Have Features
- Stable pause/resume and settings flow
- Wave system with intermission and scaling enemy mix
- At least 2 player weapons with clear roles
- Audio settings persistence (music/sfx)
- End-of-run report with meaningful stats
- Local leaderboard with name reuse (no duplicate name records)
- Reliable restart without reloading page

## Out of Scope for V1
- Multiplayer
- Live services / accounts
- In-app purchases
- Story campaign
- Mobile-first controls
- Advanced mod support

## Quality Bar
- No blocking gameplay bugs
- Consistent frame pacing on target machine
- Settings persist across sessions
- Input feels responsive and predictable
